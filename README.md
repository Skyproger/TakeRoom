# BookRoom

**TakeRoom** —  сервис для бронирования переговорных, написанный с нуля: от доменной логики на бэкенде до UI на фронтенде. Без готовых решений — только свой API, своя логика конфликтов бронирований и свой интерфейс.

## Возможности

- Просмотр офисов и переговорных, детали каждой комнаты
- Бронирование комнаты на дату и время с валидацией формы
- Защита от пересечения бронирований (conflict detection)
- Список «Мои брони» с отменой бронирования
- Продуманные состояния интерфейса: loading / empty / error
- Обновления в реальном времени через WebSocket

## Стек

### Backend — NestJS

Бэкенд написан на **NestJS 11** с адаптером **Fastify** для высокой производительности. Ключевые технологии:

| Технология | Зачем |
|---|---|
| NestJS 11 + Fastify | модульная архитектура, быстрый HTTP-слой |
| WebSocket (ws) | realtime-обновления бронирований |
| @nestjs/swagger | автогенерация OpenAPI-документации |
| Zod | валидация входных данных на границе API |
| Luxon | работа с датами и таймзонами |
| Vitest | юнит-тесты доменной логики |

Архитектура разделена на слои: `domain` (модели и ошибки), `services` (бизнес-логика), `controllers` (HTTP), `realtime` (WebSocket-шлюз), `store` (in-memory хранилище с сид-данными).

### Frontend — React

| Технология | Зачем |
|---|---|
| React 18 + TypeScript | компонентный UI |
| Redux Toolkit | управление состоянием |
| React Router | маршрутизация (список комнат, детали, мои брони) |
| Tailwind CSS 4 | стилизация |
| Vite | сборка и dev-сервер |
| Vitest + Testing Library | тесты компонентов и API-слоя |

## Запуск

Требуется Node.js >= 20.

```bash
# Backend
cd server
npm install
npm run dev

# Frontend (в отдельном терминале)
cd frontend
npm install
npm run dev
```

Полная проверка качества бэкенда (форматирование, линт, типы, тесты):

```bash
cd server
npm run check
```
